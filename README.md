# EasyBuild  — Собери комп, а не гроб

<!-- СЮДА ВСТАВИМ БЕЙДЖ ПОЗЖЕ -->

Добро пожаловать в репозиторий проекта **EasyBuild**. Это лендинг-страница сервиса по подбору и сборке персональных компьютеров с гарантией совместимости комплектующих.

Проект создан в рамках выполнения лабораторной работы по настройке CI/CD-пайплайна (Continuous Integration / Continuous Deployment) и демонстрации навыков работы с GitHub.

##  Демо-версия
Посмотреть на работающий сайт можно по ссылке: 
 **[https://cathv5.github.io/site-cicd/](https://cathv5.github.io/site-cicd/)**

##  Что внутри (Стек технологий)
* **Frontend:** Чистый HTML5 и CSS3 (без использования сторонних фреймворков).
* **Адаптивность:** Сайт корректно отображается как на десктопах, так и на мобильных устройствах.
* **Автодеплой:** Настроен собственный пайплайн через **GitHub Actions**. При каждом изменении кода в ветке `main` сайт автоматически собирается и публикуется на GitHub Pages.

##  Структура проекта
* `index.html` — основная разметка страницы.
* `styles.css` — файл со стилями и медиа-запросами.
* `.github/workflows/deploy.yml` — конфигурационный файл CI/CD пайплайна.
